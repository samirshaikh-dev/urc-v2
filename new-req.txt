Your new Contact Us requirement should follow a **database-first enquiry workflow**. The most important rule is that neither email nor WhatsApp communication should happen before the enquiry is successfully saved in the database.

I recommend implementing two separate submission flows using the same backend enquiry API.

## **1. Workflow architecture**

**Option A — Submit Enquiry**

1. Customer fills in the contact form.
2. Frontend sends form data to backend API.
3. Backend validates and saves enquiry in database.
4. Backend sends a confirmation email to the customer.
5. Display successful submission message.

**Option B — Submit via WhatsApp**

1. Customer fills in the same contact form.
2. Frontend sends form data to backend API.
3. Backend validates and saves enquiry in database.
4. Backend returns the saved enquiry ID and WhatsApp message details.
5. Frontend opens WhatsApp with a prefilled enquiry message.
6. Customer reviews and manually sends the WhatsApp message.

**Important:** Opening WhatsApp with a prefilled message is not the same as automatically sending a WhatsApp message. Automatic sending requires the WhatsApp Business Platform / Cloud API.

## **2. Suggested database structure**

Create an `enquiries` table/collection.

| Field               | Purpose                                       |
| ------------------- | --------------------------------------------- |
| id                  | Unique enquiry ID                             |
| fullName            | Customer name                                 |
| companyName         | Company name                                  |
| businessEmail       | Email address                                 |
| phoneNumber         | Optional phone                                |
| productInterestedIn | Selected product                              |
| requirementDetails  | Customer requirements                         |
| submissionMethod    | `email` or `whatsapp`                         |
| emailStatus         | `pending`, `sent`, `failed`, `not_applicable` |
| whatsappStatus      | `initiated`, `not_sent`, `sent`               |
| createdAt           | Submission timestamp                          |

Keep the enquiry record even if email delivery fails. A communication failure must never erase a successfully saved enquiry.

## 10. UI/UX Design Requirements — Minimal & Customer-Friendly

The Contact Us form and all related states (loading, success, error, and email confirmation) must follow a minimal, modern, customer-friendly design approach.

### Design Philosophy

- Keep the interface clean, simple, and professional.
- Prioritize readability and ease of use over decorative elements.
- Make the enquiry process feel approachable and effortless.
- Maintain consistency with the existing website's design system and brand identity.
- Avoid unnecessary visual complexity.

### Form Design

- Preserve the existing form layout and visual hierarchy.
- Use clear, readable field labels.
- Use helpful placeholder examples instead of technical instructions.
- Clearly indicate required and optional fields.
- Maintain comfortable spacing between fields.
- Use subtle borders, rounded corners, and light neutral backgrounds.
- Provide visible focus states when users interact with inputs.
- Make validation messages short, friendly, and positioned near the relevant field.
- Ensure dropdowns and textareas are easy to interact with on mobile.

### Button Design

**Submit Enquiry**
- Use the primary brand color.
- Include a simple directional arrow icon.
- Show a clear loading state while processing.

**Submit via WhatsApp**
- Use a secondary outlined button.
- Include a WhatsApp icon.
- Make its purpose immediately understandable.
- Show a loading state while saving the enquiry.

Both buttons should have consistent dimensions, spacing, and accessible touch targets.

### Success State

After successful database persistence, display a friendly confirmation message.

Suggested content:

**Thank you! Your enquiry has been received.**

We've received your requirements and our team will review them shortly. We'll get back to you as soon as possible.

Use a subtle success icon and a clean confirmation layout. Avoid intrusive popups or unnecessary animations.

If the confirmation email fails, show a reassuring message that the enquiry was received but email confirmation could not be delivered.

### WhatsApp Experience

After the enquiry is saved successfully, open WhatsApp with a prefilled, well-formatted message.

Keep the message:
- Short and readable.
- Professionally structured.
- Easy for the customer to review before sending.
- Inclusive of the enquiry reference number.

Do not automatically claim that the WhatsApp message has been sent.

### Email Template Design

Create a minimal, responsive HTML email template consistent with the website's branding.

Customer confirmation email should include:

1. Brand logo or company name.
2. Friendly greeting.
3. Clear enquiry received confirmation.
4. Enquiry reference number.
5. Brief summary of submitted requirements.
6. Expected next step.
7. Company contact information.

Design guidelines:
- White background.
- Clean typography.
- Subtle dividers.
- Comfortable padding.
- Mobile-friendly layout.
- Minimal use of brand colors.
- No unnecessary graphics, gradients, or promotional banners.

### Responsive Design

- Mobile-first implementation.
- Single-column form layout on smaller screens.
- Full-width buttons where appropriate.
- Adequate spacing between interactive elements.
- Prevent horizontal scrolling.
- Ensure WhatsApp redirection works correctly on mobile and desktop.

### Accessibility

- Proper form labels and semantic HTML.
- Keyboard-accessible controls.
- Sufficient color contrast.
- Accessible error and success announcements.
- Visible keyboard focus indicators.
- Do not communicate validation or success through color alone.

### Final Design Principle

The customer should be able to understand the form immediately, fill it in without confusion, and confidently submit their requirements.

Do not redesign the entire website. Focus only on improving the Contact Us enquiry experience while respecting the existing brand identity.
