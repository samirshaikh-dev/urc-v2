# Brand Color System — United Rubber Cork

Confirmed brand palette and UI application system for the United Rubber Cork website redesign.

## Confirmed Brand Palette

| Token / Role | Color Name | Hex Code | Intended UI Treatment |
|---|---|---|---|
| **Primary** | Deep Maroon | `#650510` | Logo, primary buttons, hero panels, footer, and active navigation |
| **Secondary** | Orange | `#F58634` | Supporting highlights, contact sections, active indicators, and links |
| **Accent** | Yellow | `#FCC813` | Small highlights, icons, and decorative emphasis |
| **Background** | Light Grey | `#F5F5F5` | Main page and header background |
| **Form Surface** | Very Light Grey | `#F1F2F3` | Input fields and form backgrounds |
| **Elevated Surface** | Pure White | `#FFFFFF` | Cards, elevated surfaces, and clean content blocks |
| **Borders** | Soft Grey | `#E5E7EB` | Subtle dividers and outlines |
| **Text Primary** | Deep Charcoal | `#1A1A1A` | Headings, labels, and primary body text |
| **Text Muted** | Slate Grey | `#5A5D63` | Supporting metadata and descriptions |

| UI Element | Recommended Treatment |
|---|---|

| **Hero** | Large product visual with a maroon content panel (`#650510` with white text) |
| **Primary CTA** | Maroon background (`#650510`) with white text (`#FFFFFF`) |
| **Secondary CTA** | White background with maroon border (`border-[#650510] text-[#650510]`) |
| **Active Navigation** | Maroon text with orange underline (`#F58634`) |
| **Product Sections** | Light grey (`#F5F5F5`) and pure white (`#FFFFFF`) surfaces |
| **Section Highlights** | Small orange details (`#F58634` kickers, indicator dots) |
| **Footer** | Deep maroon (`#650510`) with white text and yellow accents (`#FCC813`) |
| **Contact Form** | Very light grey fields (`#F1F2F3`) with maroon focus states (`focus:ring-[#650510]`) |

## Accessibility and Color Usage Rules

1. **High Contrast on Deep Maroon**: Always use white text on `#650510` (contrast ratio > 11.8:1, AAA compliant).
2. **Accessible Orange**: On orange backgrounds (`#F58634`), prefer dark charcoal text (`#1A1A1A`) for smaller text.
3. **Restrained Yellow**: Use yellow (`#FCC813`) only for small highlights, icons, or badges—never for large blocks of body copy.
4. **No Gradients**: Avoid orange-to-yellow gradients or neon effects.
5. **Neutral Dominance**: Keep neutral backgrounds (`#F5F5F5`, `#FFFFFF`) dominant. Brand colors provide identity, while whitespace and clean surfaces create the premium appearance.
6. **No Cork Brown**: Do not introduce or reintroduce the previous cork-brown palette (`#A77B52`).
