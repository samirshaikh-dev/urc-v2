### Overall layout

- Fixed sidebar: Approximately 230px wide.
- Main content: Flexible width with 32–40px padding.
- Background: Warm off-white.
- Sidebar: Same background, separated by a subtle vertical border.
- Content: Minimal tables, clear typography, subtle borders.
- Actions: Small square icon buttons.

## 4. Main content area

The reference uses a very simple content structure:

Page header

- Page title on the left.
- Add new button on the right.

Data table

- Title
- Slug
- Status
- Actions

Recommended improvements:

- Row hover background.
- Truncated titles with full title on hover.
- Published / Draft status indicators.
- Edit and delete icon buttons.
- Responsive horizontal scrolling on smaller screens.
- Consistent row heights.

## 6. My recommendation

Don't just copy the screenshot. Use its design language consistently across every admin page.

- Blogs → Table layout.
- Products → Table layout.
- Media → Grid layout.
-  Contact  → Clean form layouts.

The goal: One consistent admin design system, not separate-looking pages.
